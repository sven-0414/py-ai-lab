Exercise 6
Rewrite these backlog items as user stories (As a ..., I want ..., so that ...):
a) Add login
b) Export orders to Excel
c) Dark mode

a) As a registered user, I want to log in to my email with a password, so I can access my mail.
b) As a sales administrator, I want to export the order list to Excel, so that I can analyse the 
figures and share them with colleagues.
c) As a user with sensitive eyes, I want to switch the interface to a dark theme, so that my eyes 
aren’t strained.

Exercise 8
Write a Definition of Done for a team of four developers. Include at least five points.

A backlog item is considered Done when all of the following are true:

The code is written and meets the acceptance criteria.
Automated tests exist and pass.
The code has been reviewed by at least one other developer.
The code follows the team’s agreed standards.
The change is documented.
The feature has been deployed .

Exercise 9
A team's Daily Scrum takes 45 minutes. Everyone stands facing the manager and reports what
they did. What is wrong, and what would you suggest?

- The meeting is far too long.
- The team is facing the manager which signals the meeting is a status report upward rather than a team conversation.
- Reports what they did, suggests the focus is backward-looking and individual, not forward-looking and collective.

Exercise 10
Scrum or Kanban? Choose for each team and explain why.
a) A team building a new mobile app
b) An IT support desk
c) A team fixing bugs in a webshop that is already live

a) Scrum – Building something new from scratch, the work is largely unknown and needs to be discovered as you go.
b) Kanban – Unpredictable work, Kanban is built for contiuous flow.
c) Kanban – Bug reports arrive on their own schedule and with different priority. Will not fit a sprint.
